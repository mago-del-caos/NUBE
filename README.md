# ☁️ Generador de Nubes de Palabras (WordCloud Customizer)

Una aplicación web interactiva y de alta calidad construida con **Python** y **Streamlit** para generar nubes de palabras estéticamente atractivas. Permite un control total sobre la paleta de colores y la resolución final de la imagen.

## ✨ Características
- **Paleta de Colores Personalizada:** Elige hasta 4 colores exactos para las palabras y un color para el fondo usando selectores hexadecimales.
- **Alta Resolución:** Genera y exporta imágenes a 300 DPI, ideales para presentaciones, portadas o impresión.
- **Renderizado Dinámico:** Ajusta el ancho, alto y la cantidad máxima de palabras en tiempo real.
